=========================================
 命令行待办清单《我的待办》 - 项目说明文档
=========================================

【一、项目简介】
本项目是 Python 课程大作业，一个基于控制台运行的待办清单管理程序。
包含任务增删改查、筛选排序、统计、数据持久化，以及导出 HTML 报告和 OpenCV 生成统计图的附加功能。

【二、运行说明】
1. 环境要求：
   - Python 3.8 及以上版本
   - 需安装第三方库：opencv-python, numpy (用于加分项统计图)
2. 依赖安装：
   打开终端（或 PyCharm 内置 Terminal），输入以下命令：
   pip install opencv-python numpy
3. 启动程序：
   在终端输入：python main.py
   （程序启动后会自动读取同目录下的 todo_list.txt，若不存在则自动创建）
4. 产物说明：
   - 选择菜单 6：生成 report_日期.html 报告文件，双击浏览器打开查看。
   - 选择菜单 7：生成 chart.png 统计图，双击图片查看。
